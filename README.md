<h1 align="center">Dramatic Deaths</h1>

<p align="center">Every death is a movie scene.</p>

<p align="center"><a href="https://modrinth.com/mod/dramatic-deaths">Modrinth page</a></p>

When you die, the game drops into slow motion, the camera breaks free from your body and a short cinematic plays, made for exactly how you died. Then a dark end screen gives you the title and a random line.

## Features

- **A scene for every death:** killcams for mobs and players, plus their own camera moves, colors, particles and sounds for explosions, falls, drowning, fire, freezing, the void, lightning, anvils, magic and starving
- **Titles that react:** lava burns the letters, water sinks them, an anvil flattens them, bites get taken out when you starve
- **Never the same twice:** over 200 hand-written lines in English and German, with lines for about 30 mobs
- **Skip any time,** with hardcore support
- **Client-side only:** works on any server, and nobody else needs it

## Requirements

- Minecraft 26.3 with Fabric Loader 0.20.1 or newer
- Java 25

Fabric API isn't needed.

## Building

```
./gradlew build
```

The jar ends up in `build/libs`.
